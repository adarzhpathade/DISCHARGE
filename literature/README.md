# literature/

| File / folder | Purpose |
|---|---|
| `annotated_bibliography.md` | Every paper used: citation, summary, key findings, relevance, and verification status |
| `literature_review.md` | Draft of report Chapter 2 (P4-08). Polished in Week 8 |
| `papers/` | Downloaded PDFs (gitignore them if your repo is public and the licences are unclear) |

## PDF naming convention
`<YYYY>_<FirstAuthorSurname>_<ShortTitle>.pdf`, e.g.
- `2014_Strack_HbA1c-Readmission-70000-Records.pdf`
- `2010_vanWalraven_LACE-Index.pdf`
- `2011_Kansagara_Readmission-Models-Systematic-Review.pdf`

## Workflow
1. Find the paper (Google Scholar, PubMed, PMC for free full text).
2. Save the PDF to `papers/` using the naming convention.
3. Add or update its entry in `annotated_bibliography.md` (use the template there).
4. Set **Verified** to ✅ only after you have checked the title, authors, journal, year, volume, pages and DOI against the publisher or PubMed page.
5. Cite in the report using the bibliography key (e.g., `[Strack2014]`) and convert to IEEE/APA at the end (P8-09).

## Where to search
- Google Scholar: "hospital readmission prediction machine learning", "30-day readmission diabetes UCI", "LACE index validation"
- PubMed / PMC (free full texts)
- arXiv (cs.LG) for ML methods
